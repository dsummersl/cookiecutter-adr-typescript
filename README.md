# Overview

A [cookiecutter](https://github.com/cookiecutter/cookiecutter) template that creates a basic TypeScript project.
- Includes [adr-tools](https://github.com/npryce/adr-tools) to record architectural decisions
- Includes [knip](https://github.com/webpro/knip) for dead code / unused dependency detection
- Includes [treepeat](https://github.com/) for duplicate/similar code detection
- Runs TypeScript directly with [tsx](https://github.com/privatenumber/tsx)
- Measures code coverage with [vitest](https://vitest.dev/) v8 coverage
